Beamer+

Interactive Presentations

As someone who teaches and presents technical topics often, I found myself limited by the static nature of traditional LaTeX slides. I wanted a way to create a more dynamic experience that would allow me to seamlessly integrate videos, audio, and interactive widgets, while maintaining the beautiful typesetting of LaTeX. That's why I created Beamer+.

What Is Beamer+?

Beamer+ is a lightweight web-based presentation app built with Python and Flask that enhances LaTex slides with the following features:

Embedded Media Support

Seamlessly insert videos, 3D models, and audio directly into your slides.

Live Polling

Run real-time polls with automatic AI summaries of audience responses.

Annotation Tools

Draw, highlight, and mark up content during your presentation.

Easy Navigation

Navigate slides using keyboard shortcuts, touch inputs, or a mouse.

Custom Widgets

Add custom interactive widgets to enchance presentations even further.

With Beamer+, you can turn a static PDF into a more engaging and interactive lecture or demo—perfect for classrooms, conferences, or online content creation.

See Beamer+ in action with embedded media and annotations

How It Works

Beamer+ leaves your LaTeX alone. You write and compile slides the way you always have, and Beamer+ adds interactivity on top of the finished PDF. Everything runs from a single Flask server in the browser, either on your own laptop or on a shared server that hosts many lectures at once.

Step 1

Write your slides as usual

Build your deck in Beamer, or any tool that exports a PDF, and compile it. Your typesetting, equations, and theme come through exactly as you designed them.

Step 2

Load it into Beamer+

Upload a plain PDF and each page becomes a slide. Or upload a presentation ZIP: the PDF bundled with its saved configuration, media, widgets, and AI models. A fully set-up lecture then moves between machines as a single file.

A presentation ZIP can include code that runs on the server, so only open ZIPs from people you trust.

Step 3

Add interactivity

In the editor, place videos, audio, 3D models, or widgets onto any region of a slide. Each widget describes its own settings, so Beamer+ builds its configuration panel automatically.

Python REPLCalculatorBrowserCameraMapsPolls

Need something else? A custom widget is a single self-contained HTML file. When you're done, save the whole deck as a presentation ZIP.

Step 4

Present live

Move through slides with the keyboard, mouse, or touch, and draw directly on the content as you talk.

Audience-response widgets put a QR code on screen. Students answer from their phones with open text, a word cloud, or multiple choice, and responses stream back in real time. An AI model (Claude or GPT-4o) can then summarize what the room said.

Getting Started

There are two ways to start using Beamer+:

1

Try the Live Demo

The quickest way to see Beamer+ in action. Visit beamer.changapp.net in your browser. There's nothing to install.

2

Run Your Own Server

Download the latest source code from the GitHub repository and follow the setup instructions to start your own Beamer+ server.
